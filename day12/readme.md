Day 12 – Pivot Tables

Today I learned how to properly use Pivot Tables in Excel — one of the most powerful tools for analyzing data quickly.

I practiced creating pivot tables from a structured table and selecting exactly what data I want to analyze and how it should be aggregated (sum, count, average, etc.).

I also learned about grouping, both manual and automatic, which makes it easier to organize large datasets into meaningful categories.

From there I explored:
	[-] Pivot table charts for quick visualization
	[-] Slicers and timelines to make the analysis interactive
	[-] Filter connections to control multiple pivot tables with the same slicer

One trick I learned today was how to create separate pivot tables from the same data source.

Normally, Excel links pivot tables together using the same pivot cache to save memory. This means grouping or changes in one pivot table can affect the others.

But if you want them to behave independently, you can create a pivot table using:

Alt + D + P

Then follow the wizard and select “No” when it asks if the pivot table should be associated with the existing one.

That small trick gives you much more flexibility when building dashboards.
