Day 7 – Excel Formulas, Functions 

Today was a practical Excel day — and it felt like leveling up.

First, I practiced comparison operators, comparing values to constants and then to other cells using proper cell referencing (relative, absolute and mixed).

Then I worked with core functions:
	- COUNT, COUNTIF
	- AVERAGE, AVERAGEIF
	- Logical functions like IF and IFS

I also paid attention to errors and what they actually mean, for example: “#DIV/0!” — the formula is trying to divide by 0

Then I moved into statistical functions:
	- Standard deviation (and the difference between STDEV.P and STDEV.S)
	- Quartiles (and the difference between QUARTILE.INC and QUARTILE.EXC)
	- Mean, median, mode
	- Ranking

This wasn’t new theory, I’ve learned these concepts before.

But applying them directly in Excel made everything more practical.
