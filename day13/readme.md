Day 13/120 – Advanced Data Analysis

Today I learned about Excel add-ins and some built-in analytical tools.

First, I explored the Forecast Sheet feature, which uses historical time-series data to generate predictions and automatically creates a forecast chart with confidence intervals. It’s a quick way to estimate future values based on past trends.

Then I worked with What-If Analysis tools:
[+] Scenario Manager – used to simulate different scenarios by changing multiple input values and seeing how they affect the final result.

[+] Goal Seek – helps determine what input value is required to achieve a specific result.

[+] Data Tables – used to test how changes in one or two input variables affect a formula’s output.

After that, I learned to use the Solver add-in, which is more advanced than Goal Seek. Solver finds an optimal value for a formula by adjusting selected variable cells while respecting constraints you set.

Finally, I explored the Data Analysis ToolPak, which provides tools for quick exploratory data analysis such as:
[+] Sampling
[+] Regression analysis
[+] Histograms
[+] Descriptive statistics
