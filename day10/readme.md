Day 10/120 – Spreadsheet Advanced

Today was about taking spreadsheets beyond basic usage.

-Tables-

I learned how powerful Excel Tables really are.

They’re not just formatted ranges — they behave almost like mini-databases.

I worked with structured references like:

[@salary_year_avg]

Seeing how table names can be referenced like variables inside a workbook made everything feel cleaner and more dynamic.

I also explored functions that work especially well with tables, like:
[-] SUBTOTAL()
[-] AGGREGATE()

And table slicers, which make filtering interactive and dynamic without touching formulas.

⸻

-Formatting-

I revisited basic cell formatting but focused more on conditional formatting, setting rules that automatically change how data looks based on conditions.

Instead of manually highlighting values, I let Excel do the thinking.

I also learned how to properly clear and manage formatting.

⸻

-Collaboration-

I learned how to:
	[-] Name cells and ranges
	[-] Protect worksheets and workbooks
	[-] Lock specific cells

Now I can control which parts of a workbook people can edit and which parts stay protected.

That’s not just technical skill — that’s workflow design.

⸻
