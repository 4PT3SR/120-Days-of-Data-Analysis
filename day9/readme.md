Today I learned about charts,  but more importantly, when to use each one.

Because charts aren’t just decoration.
They’re decision tools and they make it easier to read data.

For basic charts:
	[x] Line charts – perfect for time series data. They clearly show trends over time and how values are connected.
	[x] Pie charts – useful for showing proportions, though only when categories are limited.
	[x] Column and bar charts – great for comparing categories side by side.

Then I moved into more advanced visuals:
	[x] Scatter plots – powerful for comparing two numerical variables and spotting relationships or correlations.
	[x] Maps – helpful when location matters and you want to see geographic patterns.

For statistical charts:
	[x] Histograms – show distribution and frequency.
	[x] Box and whisker plots – summarize spread, median, quartiles, and outliers in one view.

And finally, sparklines — small, compact charts inside cells that quickly show trends without taking much space.

Choosing the wrong chart can mislead.
Choosing the right one makes insight obvious.
