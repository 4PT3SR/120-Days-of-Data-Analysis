Today I learned about Power Query, one of the most powerful tools in Excel for working with data.

I learned how to import data from different sources, as well as how to load and work with multiple datasets at once. Instead of manually cleaning or combining data, Power Query allows you to transform and merge datasets in a structured way.

I also practiced combining data, which is useful when dealing with files coming from different sources or different periods.

Finally, I spent time getting familiar with the Power Query Editor environment, understanding where transformations happen and how data can be cleaned and shaped before loading it into Excel.
