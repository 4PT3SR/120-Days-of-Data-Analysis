Day 6 – Introduction to Excel

Today was about the basics of Excel, not learning them for the first time, but re-familiarizing myself properly.

I worked on:
	- Moving and copying worksheets between workbooks
	- Manipulating worksheets
	- Text concatenation using “&”
	- Working with ranges
	- Understanding the ribbon and tabs more intentionally

Nothing flashy, just fundamentals.

But the real highlight today wasn’t even Excel itself.

It was setting up Windows on a VM on my Mac, as I realized Excel on Mac has some limitations compared to Excel on Windows, especially for more advanced data work.

That small decision felt important.
