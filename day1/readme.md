Data
These are raw facts, figures or observations that can be collected, stored, processed to produce meaningful information

Types of data
Quantitative: data that can be counted/measured
Qualitative: data that describes/ shows characteristics / qualifies

Data formats
Structured: Organised e.g rows n columns
Unstructured: Not organised e.g photo
Semi-structured: has structure but not rigid like a database e.g json

Why is data important?: It is the foundation of analysis and decision making


Data Analysis
 Process of analyzing raw data in order to draw meaningful insights used to inform and drive decisions

 Types of Data Analytics
 - Descriptive: What happened? {hindsight}
 - Diagnostic: Why did it happen? {insight}
 - Predictive: What will happen? {foresight}
 - Prescriptive: What should we do? {recommendation}

 Who is a data analyst?
  Collects, processes 'n' analyzes data to help organization make informed decision

  Steps to Analyze Data
  - Step I: Define the question
  -Step II: Collect the data
  -Step III: Clean the data
  -Step IV: Analyze the data
  -Step V: Visualize and share findings
