Hypothesis and Regression
Today I learned regression analysis.

Regression helps answer one key question:

If X changes, what happens to Y?

It measures the relationship between variables and helps with prediction.


I also saw how it connects to hypothesis testing:
	•	H₀: No relationship
	•	H₁: There is a relationship

If the p-value is small enough (like < 0.05), we reject the idea that there’s no relationship.

Regression shows the relationship.
Hypothesis testing checks if it’s statistically meaningful.
