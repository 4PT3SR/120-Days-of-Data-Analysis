Day 8 – Arrays, Lookups & Working Smarter in Excel

Today was heavy on Excel

I learned about array formulas, both classic and modern (dynamic arrays). The concept that one formula can return multiple values and spill automatically into corresponding cells makes things easier.

Multiplying one column by another and having Excel generate a whole range instantly? That changed how I see calculations.

Functions like UNIQUE() and SORT() being used on arrays makes cleaning and organizing data much faster.

I even picked up small practical tricks, like using:
TEXT("25-02-2026","mmm")
to extract the month as text. Simple, but useful.


Then I moved into lookup functions:
	- VLOOKUP
	- HLOOKUP
	- XLOOKUP


For text functions, I worked with:
	- TEXTJOIN() for combining text cleanly
	- TEXTSPLIT() and RIGHT() for extracting parts of strings
	- FIND() and MID() for locating and pulling specific characters

And a small but powerful trick:
TRANSPOSE(array) — flipping data from horizontal to vertical instantly.


Finally, I worked with date and time functions:
	- Extracting DAY(), MONTH(), and YEAR()
	- Using DATEDIF() to calculate differences between dates
	- Extracting HOUR(), MINUTE(), and SECOND() from time values
